# ASTRUM

Zwei Raumschiffe, eine Rechnung. Ein 3D-Spiel für zwei Personen an einem Gerät — im Browser.

## Spielen

1. **Gegeneinander** oder **Miteinander** wählen.
2. Jede Person wählt eine Schiffsklasse und eine Rechenklasse.
3. **Start**.

### Schiffsklassen

| Schiff | Rolle | Besonderheit |
| --- | --- | --- |
| Pfeil | Jäger | Schnell, wendig, kurze Salve |
| Bastion | Kreuzer | Langsamer, mehr Zeit für die Schildrechnung |
| Schatten | Phantom | Kleine Silhouette, startet mit Streufeuer |
| Komet | Nova | Schwere Schüsse, hohe Wucht |

### Waffen

Impuls, Zwilling, Streu, Rail, Nova. Im Duell steigt die Waffe, wenn der Gegner die Rechnung falsch löst. Im gemeinsamen Flug steigt sie mit jedem Abschuss.

Fünf Leben. Eine richtige Antwort hält den Schild, es wird nichts abgezogen.

### Steuerung

**Miteinander** (Flug in den Sektor, Kamera hinter den Schiffen)

- Spieler 1: W Schub, S Bremse, A links, D rechts, Q hoch, E runter, Leertaste Feuer
- Spieler 2: Pfeile, I hoch, K runter, rechte Umschalt Feuer

**Gegeneinander** (ein Schiff links, eins rechts)

- Spieler 1: W/S hoch und runter, A/D links und rechts, Leertaste Feuer
- Spieler 2: Pfeiltasten, Enter Feuer

Auf dem Handy gibt es Steuerkreuze und eine Feuertaste.

Der spielbare Stand läuft in der Vorschau. Quelltext der Simulation: `src/game`.
